# Moja Hudba

Hudobný prehrávač (PWA) – prehráva skladby z tvojho mobilu, má sleep timer, rad „Ďalej“ (swipe doprava = zmazať, potiahnutie ≡ = zmena poradia) a náhodné poradie.

## Ako to dať na telefón
1. Na GitHube vytvor nový repozitár (napr. `hudba`) a nahraj doňho všetkých 5 súborov: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`.
2. Repozitár → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
3. Po ~1 minúte bude appka na `https://TVOJE-MENO.github.io/hudba/`.
4. Otvor odkaz v Chrome (Android) alebo Safari (iPhone) → **Pridať na plochu / Inštalovať aplikáciu**.
5. V appke ťukni na **Pridať skladby** a vyber hudbu z telefónu. Skladby ostanú uložené v appke.
